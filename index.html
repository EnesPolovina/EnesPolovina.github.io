How I work

AI does the typing. The process is mine.
  1. 01 / Research

    Read the options first

    The wrong library is a decision you live with for a year, not a line you delete. I go through the alternatives before anything gets written.

  2. 02 / Tests

    They ship with the feature

    New code arrives with its tests. Not afterwards, not once there's time — that time never shows up.

  3. 03 / Agents

    Written to my spec

    I build agents with custom skills and explicit instructions, so the tests they generate check what I decided matters, not what a model assumed I meant.

  4. 04 / CI

    The gate holds

    GitHub Actions runs the suite on every pull request. Nothing merges on a promise that it probably works.
